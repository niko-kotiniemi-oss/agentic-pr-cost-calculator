# B-009: A report on a pull request still in progress

- **Status:** Planned
- **Last changed:** 2026-11-13
- **Brief:** A report that can be run before a pull request merges and shows it as still in progress, where the first version reports only at the merge.
- **Rests on:** DR-223, DR-005
- **Issue:** none
- **Pull requests:** none

## Problem

The report runs once, when a pull request merges (DR-005), so nobody can see what an open pull request has cost so far.

## What done looks like

The report can be run on a pull request that has not merged, and what it shows says that the pull request is still in progress, so that its figure is never read as the final one (DR-223).

None.
