# B-016: An organization mode

- **Status:** Open to feedback and contributions
- **Last changed:** 2026-11-13
- **Brief:** An organization mode, in which an organization turns its members' capture on and they cannot turn it off. Nothing in the first version rules it out.
- **Rests on:** DR-189
- **Issue:** none
- **Pull requests:** none

## Problem

In the first version, each person opts in for themselves and can always turn capture off (DR-189). An organization that wants every member's usage counted has no way to require it.

## What done looks like

An organization can turn its members' capture on in a way that they cannot turn off, with its own spec, threat review and the owner's decision, and the README says plainly what it means for the people it covers.

## Postponed points

None.
