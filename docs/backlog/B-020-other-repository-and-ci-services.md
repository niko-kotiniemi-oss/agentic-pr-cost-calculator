# B-020: Other repository and CI services

- **Status:** Open to feedback and contributions
- **Last changed:** 2026-11-13
- **Brief:** Repository and CI services other than GitHub, such as GitLab or Gitea.
- **Rests on:** DR-160
- **Issue:** none
- **Pull requests:** none

## Problem

GitHub is the only repository and CI service that the first version supports (DR-160), so a project kept elsewhere cannot use the tool.

## What done looks like

The tool runs on at least one other service, such as GitLab or Gitea, with its report posted where that service shows a merge request's discussion.

## Postponed points

None.
