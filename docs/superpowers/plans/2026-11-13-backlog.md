# Backlog items and the roadmap as their index: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build task 1.27 of `add-pr-cost-calculator`: one backlog item per roadmap item, the roadmap rewritten as their index, the README's briefing for developers, and the tests that hold R206, R207 and R209 to R218.

**Architecture:** The pages are Markdown, checked by pytest. `tests/test_roadmap.py` keeps the roadmap's sections, its risks and the link and hidden-text checks, which now read `docs/backlog/` too. A new `tests/test_backlog.py` reads the items, checks their form, their names, the roadmap's index and Later, the comparison with the base commit, the backlog's page and the README's briefing. It imports the roadmap test's helpers and synthetic tree, and `base_commits` from `tests/test_decisions.py`, so that both compare with the same base.

**Tech Stack:** Python 3.11 standard library, pytest, git.

**Spec:** `openspec/changes/add-pr-cost-calculator/specs/project-standards/spec.md` (R206, R207, R209 to R218), design decision 12 and 14 in `openspec/changes/add-pr-cost-calculator/design.md`, records DR-225 to DR-229.

## Global Constraints

- No test uses the network; the synthetic trees are git repositories made in `tmp_path`, with the session's `GIT_` variables removed.
- The roadmap, every file in `docs/backlog/` and each feature page's section on known limitations and the roadmap hold printable ASCII and line feeds only, no `<`, `&`, backslash or `]:`, no web address, no at sign, no image, no fenced or indented code, no space in inline code, and links only to headings of their own page or tracked files inside the repository.
- Issues and pull requests are named by number, never linked.
- Nothing private: the Now items are written for public readers, and the owner reads them, with the commit message and the pull request text, in the project's files before the branch that holds them is pushed.
- Each check is shown to fail on a synthetic tree into which its defect is planted, and a check that examined nothing fails.

## Review Focus

- A brief with an abbreviation such as "e.g. " counts as two sentences: the briefs avoid abbreviations, and the sentence rule is the design's (a stop, question mark or exclamation mark followed by a space or the end).
- A branch whose base is not the default branch: the comparison runs against every base that `base_commits` gives, as the records' check does.
- A day boundary in UTC between the base's date and the run: the date check reads the day in UTC, passed in as a parameter so that tests fix it.
- An item listed under Now and under Later at once: counted as listed twice.
- A status written with a trailing stop or in other case, such as `Planned.` or `planned`: not one of the five.
